### Highlights so far

- Pure Go implementation of [RFC 9849] (TLS Encrypted Client Hello)
  HPKE key lifecycle management.
- Four officially maintained DNS providers: Cloudflare, AWS Route 53,
  Akamai Edge DNS, PowerDNS.
- Community-maintained provider directory with a "hello world" mock
  template and contribution guide.
- Hardened systemd unit + non-root system user + interactive
  install/uninstall scripts.
- 153 unit tests at time of writing; full CI matrix on Linux/macOS/Windows
  across Go 1.22 – 1.25.

[RFC 9849]: https://www.rfc-editor.org/rfc/rfc9849.html
